## Обо мне

Я frontend-разработчик с опытом создания клиентских частей веб-приложений.

Работаю с React и TypeScript, превращаю макеты Figma в быстрые, адаптивные и поддерживаемые интерфейсы. Люблю разбираться в архитектуре приложений, улучшать пользовательский опыт и находить простые решения для сложных задач.

- Разрабатываю интерфейсы по макетам Figma
- Создаю адаптивную и семантическую верстку
- Исправляю ошибки и занимаюсь рефакторингом
- Провожу code review
- Работаю с компонентной архитектурой и клиентским состоянием
- Постоянно изучаю современные инструменты frontend-разработки
